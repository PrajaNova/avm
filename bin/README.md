# avm — Any Version Manager

Manage Node.js, Java and Android SDK versions per project on macOS, Linux and Windows.
This npm package downloads the matching Rust binary and provides `avm` and `avm-bin`.

```bash
npm install -g @prajanova/avm
```

Visit **[getavm.dev](https://getavm.dev/)** for shell setup, quick start,
all commands and the plugin marketplace.
